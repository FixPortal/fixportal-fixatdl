# Golden contract JSON

These files are the wire JSON (`AtdlStrategiesDto`, camelCase, nulls omitted)
that FixPortal Simulator emitted at commit `7a287c2`, before the mapper moved
into `FixPortal.FixAtdl.Contracts`. They were captured from the simulator's own
`AtdlParser` + `AtdlDtoMapper`, not generated by this package.

Do not regenerate them from this package. A golden that disagrees with the
package means the package changed the wire contract consumed by
`@fix-portal/fixatdl-react`; that is a breaking change, not a snapshot update.

Sources:

| Golden | Input |
|---|---|
| `twap`, `multi-strategy`, `editref-staterule` | `../Fixtures/*.atdl.xml` |
| `pov` | `tests/FixPortal.FixAtdl.Tests/Fixtures/pov.xml` |
| `tz-clock`, `regions-enums` | `tests/FixPortal.FixAtdl.Tests/Fixtures/RealWorld/*.xml` |

Each file is one compact JSON document followed by a single `\n`.

Line endings inside `sourceXml`: the capture ran on Windows, where
`XElement.ToString` writes `\r\n`. The simulator serves from a Linux container,
so its real wire output has `\n`. The files were corrected once, mechanically
(`\r\n` to `\n` inside `sourceXml` only; nothing else in them contained a CR),
and the golden test normalises its own slices to `\n` so it passes on every OS.
